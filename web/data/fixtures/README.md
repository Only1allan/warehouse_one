# Demo and evaluation fixtures

Everything here is **synthetic** and generated by `npm run fixtures` (see `scripts/make-fixtures.mts`):

- `images/delivery-note-*.png`, `images/loading-sheet-5521.png`: rendered documents that match the seeded purchase orders and the 50-pallet sales order. Some are styled to look photographed (rotation, shadow, blur).
- `images/shelf-NN.png`: stylised shelves with a known number of cartons (`NN`).
- `audio/question-NN.wav`: spoken questions (16 kHz mono) produced by QVAC text-to-speech.
- `manifest.json`: the true values for every fixture. The eval script scores against it.
- `ask-cases.json`: questions with the tool the copilot is expected to choose.

## Adding real photos (recommended)

The image features are only convincing on realistic inputs. Put real photos in `real/`:

- `real/delivery-note-<anything>.jpg` with a matching entry in `real/manifest.json`
- `real/shelf-<count>.jpg` where `<count>` is the true number of items, for example `shelf-24.jpg`

`real/manifest.json` uses the same shape as `manifest.json` (`notes` and `shelves` arrays, paths relative to this folder). Do not add photos that contain private customer data.
